# packaging

Package-manager manifests, generated by goreleaser on each release (`.goreleaser.yaml`).
Don't edit them by hand; the next release overwrites them.

- `scoop/machine-monitor.json`: Scoop manifest, committed here by the release workflow.
  TODO(scoop-bucket): move it to a `ContractorKeith/scoop-bucket` repo once one exists, so
  `scoop bucket add` works.
- Homebrew: the cask goes to the existing tap, `ContractorKeith/homebrew-tap`
  (`Casks/machine-monitor.rb`). Publishing needs the `HOMEBREW_TAP_GITHUB_TOKEN` repo
  secret (a token with write access to the tap); without it the cask is built but not pushed.
